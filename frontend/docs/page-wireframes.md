## 三、关键展示字段汇总

| 页面 | 展示字段 | 来源 |
|------|----------|------|
| 工作台 | 文件名、文件大小、状态、上传时间 | 上传接口 + 轮询接口 |
| 检测详情 | 原图URL、掩码图URL | 后端存储/模型输出 |
| 检测详情 | 综合风险等级（高/中/低） | 模型输出 → 后端封装 |
| 检测详情 | 综合置信度分数（0~1） | 模型输出 |
| 检测详情 | 可疑区域列表（标签+置信度+坐标） | 模型输出 |
| 检测详情 | 各模型概率（CycleGAN/DDPM/Pix2Pix/StyleGAN2） | 模型输出 |
| 检测详情 | 模型版本号 | 后端配置 |
| 检测详情 | 处理耗时 | 后端计算 |
| 检测详情 | 文字结论（中性表述） | 后端生成 |
| 报告 | 以上全部 + PDF 格式 | 后端生成 |

---

## 四、设计原则

1. **中性表述**：所有风险判定使用「疑似」「存在风险」等措辞，避免绝对化判定
2. **渐进加载**：大图使用 loading 占位 → 实际加载完成后渲染
3. **状态反馈**：上传/分析/完成/失败 四种状态有明确视觉区分
4. **离线可用**：Mock 模式下全部功能可演示，不依赖后端
